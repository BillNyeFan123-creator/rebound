# Rebound

A wave-survival arena game built for a game jam. Theme: **"bounce back"** —
when you die, you don't restart empty-handed: you pick 1 of 3 cards and come
back stronger, while the run resets to wave 1.

## Controls

| Action | Keys |
|---|---|
| Move | A / D (or arrow keys) |
| Jump | W or Space |
| Attack | X or J |
| Dash (i-frames) | Shift or K |
| Card manager | C |

Survive escalating waves of slimes (big tanks, fast small ones, blue strays,
and a boss every 5th wave). Clearing a wave unlocks a new card. Dying pauses
the game and offers a bounce-back pick; your equipped cards (3 slots) persist
across deaths, so every run you're stronger.
